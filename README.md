# homebrew-tap

[![Publish](https://github.com/m1sk9/homebrew-tap/actions/workflows/publish.yaml/badge.svg)](https://github.com/m1sk9/homebrew-tap/actions/workflows/publish.yaml)
[![Test](https://github.com/m1sk9/homebrew-tap/actions/workflows/tests.yaml/badge.svg)](https://github.com/m1sk9/homebrew-tap/actions/workflows/tests.yaml)

A third-party [Homebrew](https://brew.sh) Tap for distributing m1sk9's artifacts.

```sh
brew tap m1sk9/tap

brew install m1sk9/tap/<formura>
brew install m1sk9/tap/<cask>
```
